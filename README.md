# 生命科学前沿 · LifeSciHub

一个面向生命科学领域的学术信息与科研社区网站：

- 📰 **每日资讯（自动更新）**：发布/浏览 Nature、Science、Cell、NEJM、The Lancet 等顶刊文章；服务端定时从 PubMed 自动抓取顶刊最新文献（含真实 DOI，可直接跳转原文），管理员/编辑也可手动发布
- 🏆 **比赛动态**：与学校（杭州医学院）相关的竞赛通知，含比赛介绍、按学校竞赛目录认定的含金量（A/B/C 类）、时间线与提交作品内容；自动同步创新创业学院官网（cxcy.hmc.edu.cn）的新通知；每场比赛可跳转关联社区讨论/组队
- 🧰 **精选仓库**：收录适合科研的 Agent Skill 与 MCP 服务器（文献检索、文献管理、数据采集、论文写作等），附介绍、安装方式与使用示例，支持下载计数、收藏与用户投稿
- 💬 **社区讨论**：创建/加入社区，发帖、评论、回复、点赞
- 🤝 **招募组队**：招募帖子（竞赛队友 / 团队成员 / 科研助理等）自动汇总到「招募组队广场」
- 🧭 **学术前沿**：按研究方向（肿瘤免疫/神经科学/基因编辑/合成生物学/AI 与药物发现/单细胞组学）聚合前沿文章，内容由「顶刊动态」自动汇聚
- 👁️ **眼科AI 日报**：每天 8:00 自动检索 PubMed（**目标期刊 19 本** × 眼科 AI），按「分组 → 期刊」分区展示（每刊独立区块、含空状态）；论文**中文标题在上、英文原题在下**，摘要中英对照，附 DOI/PMC 原文链接与影响因子参考值；自动生成公众号版/网站介绍版 docx。期刊清单与分组见 `server/oph.js`（依据《眼科期刊.docx》分隔线以上部分）
- 🧠 **OpenMedAI 协作板块**：医学 AI 主题协作原生接入本站——发起主题；参与申请（**分工意向**：医生/AI工程师/数据处理等 11 类 + **排名/署名意向** 5 档 + 每周投入时长，提交后由发起人**审核**）；**认领**任务（负责人/实验/数据处理/模型/写作等 8 类）、**资助意向**（经费/算力/token/专家咨询等 11 类）、关注与 **1-10 评分**；团队分工透明展示，贡献自动计入积分榜；字段与 OpenMedAILab（Django 版）同构可互通
- 🔍 栏目筛选、期刊筛选、关键词搜索、分页
- 🔐 用户注册/登录，角色权限（user / editor / admin）

## 技术栈

- 前端：React 18 + Vite + React Router（无 UI 框架，纯手写 CSS 设计系统）
- 后端：Node.js + Express（REST API）
- 数据：轻量 JSON 文件存储（`data/db.json`），零数据库依赖，开箱即用
- 安全：登录/注册限流、会话过期、scrypt 密码哈希、安全响应头、自动备份

## 快速开始

```bash
npm install       # 安装依赖
npm run build     # 构建前端
npm start         # 启动服务（默认 http://localhost:3000）
```

打开 http://localhost:3000 即可访问（开发模式含演示账号，见下）。

### 开发模式（前端热更新）

```bash
npm run dev:server   # 终端 1：启动 API 服务（3000 端口）
npm run dev:web      # 终端 2：启动 Vite 开发服务器（5173 端口，自动代理 /api）
```

## 公开部署

```bash
cp .env.example .env     # PUBLIC_MODE=1 为公开模式：无演示账号
docker compose up -d --build     # 或 node server/index.js
```

详见 [`DEPLOY.md`](./DEPLOY.md)：Docker/systemd、域名 HTTPS（Caddy/Nginx）、备份恢复、安全说明。

## 管理后台（/admin）

管理员登录后，导航栏右侧会出现「管理后台」入口，包含 7 个面板：

1. **概览**：全站内容计数（文章/社区/帖子/评论/工具/用户/今日发布）与最新动态
2. **文章**：搜索、编辑（跳转发布页编辑模式）、删除（级联删除评论）
3. **社区**：编辑（名称/简介/类型/主题色）、删除（级联删除帖子、评论、成员关系）
4. **帖子**：查看与删除（级联删除评论）
5. **评论**：查看与删除（级联删除回复；用户也可删除自己的评论）
6. **仓库**：查看、编辑（跳转提交页编辑模式）、删除精选工具
7. **用户**：修改角色（用户 ↔ 编辑 ↔ 管理员）、删除账号（级联清理其内容）

安全规则：不能修改自己的角色、不能删除自己的账号、系统始终保留至少一名管理员。

## 核心功能说明

1. **每日发布与自动更新**：编辑/管理员可通过「发布文章」手动发布；服务端每 12 小时自动执行一次同步（启动后 8 秒执行首次）：
   - **顶刊文献**：通过 PubMed E-utilities 抓取 9 本期刊（Nature/Science/Cell/NEJM/Lancet/Nat Med/Nat Biotech/Nat Commun/PNAS）最近 14 天发表的论文，自动生成文章并附带真实 DOI（原文链接）
   - **比赛通知**：解析学校创新创业学院官网「学生竞赛 → 竞赛通知」列表（cxcy.hmc.edu.cn/xsjs/jstz/），筛选竞赛类通知，提取时间安排、截止日期与提交材料后自动入库（等级默认「待认定」，需管理员依据学校最新竞赛目录核定）
   - 均在 `server/updater.js` 中可配置；也可手动执行 `npm run update`，或在管理后台概览页点击「立即同步」
2. **比赛动态**：「比赛动态」页支持按状态（报名中/进行中/即将截止/已结束）与目录等级（A/B/C 类）筛选；详情页展示含金量认定、时间线、截止倒计时、提交作品内容与官网通知原文，并一键跳转关联社区组队交流。官网自动同步的条目在管理后台「比赛」页标记为「官网同步」，等级判定默认「待认定」。
3. **社区**：「社区」页可创建自己的社区（兴趣交流 / 竞赛组队 / 团队招募三种类型），社区内可发帖，帖子类型包括讨论、招募队友、招募成员、资源分享。
4. **招募广场**：所有「招募队友 / 招募成员」类型的帖子自动汇总到 `/recruit`，支持按类型筛选。
5. **互动**：文章、帖子与比赛动态均支持点赞与评论（评论可回复，一层嵌套）。
6. **精选仓库**：「精选仓库」页按类型（Skill / MCP）与分类（文献检索、文献管理、数据采集、论文写作、通用效率、合集导航）浏览工具；详情页提供介绍、功能亮点、安装方式与使用示例（支持一键复制）、下载计数与收藏；登录用户可通过「提交精选工具」投稿，管理员可删除条目。

## 数据存储

- 首次启动自动生成 `data/db.json`，包含完整的演示数据（12 篇文章、6 个社区、10 篇帖子、12 件科研工具、17 条评论）。
- **备份**：`npm run backup`（存至 `data/backups/`，自动保留最近 20 份）；自动更新前也会自动备份；手动复制：`cp data/db.json data/db.backup.json`
- **重置演示数据**：先停止服务，再执行 `rm data/db.json`，重启后自动重新生成。
- **手动编辑**：可停止服务后用编辑器直接修改 `data/db.json`（建议先备份；服务运行中请勿直接编辑，否则可能被运行时的自动保存覆盖）。
- 生产环境如需并发写入与更高可靠性，可将 `server/db.js` 替换为 MySQL/PostgreSQL 实现（接口保持不变）。

## 安全与运行模式

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `PUBLIC_MODE` | `0` | `1` = 公开模式：**不生成演示账号**，内容种子保留，首个注册用户自动成为管理员 |
| `SESSION_TTL_DAYS` | `7` | 登录会话有效期（天），过期自动失效并清理 |
| `RATE_REGISTER_MAX` / `RATE_LOGIN_MAX` / `RATE_WRITE_MAX` | `10` / `20` / `120` | 每 IP（写操作为 IP+用户）每小时请求上限 |
| `TRUST_PROXY` | `0` | `1` = 位于 Nginx/Caddy 反代之后（限流按真实 IP 生效） |
| `UPDATE_INTERVAL_HOURS` | `12` | 自动更新间隔（小时） |
| `BACKUP_KEEP` | `20` | 备份保留份数 |

- 用户可点击导航栏用户名进入「账号设置」修改密码
- 公开模式启动时会检查并警告残留的演示账号
